# QueueSmart

COSC4353 Group 19

## Smart Queue Management Application

QueueSmart is a front-end application designed to help users join and manage service queues while allowing administrators to monitor and manage those queues.

## Technologies

- React
- Vite
- JavaScript
- CSS
- React Router

## Current Features

- User login
- User registration
- Basic form validation
- Client-side routing

This project is currently under development for COSC4353.
